# اپ مدیریت اراک کالا

پروژه Android با Kotlin و Jetpack Compose. ورود فقط با حساب مدیر Django که با `python manage.py setup_manager` ساخته شده است. اپ مدیریت و فروشگاه از یک پایگاه داده استفاده می‌کنند.

- Android SDK 35، Gradle 8.11.1 و JDK 17 یا 21.
- برای شبیه‌ساز روی همان رایانه، Django را با `ARAK_DEVELOPMENT=1` روی درگاه ۸۰۰۰ اجرا کنید. نسخهٔ Debug به `http://10.0.2.2:8000/api` متصل می‌شود.
- برای ساخت نسخهٔ انتشار روی دامنهٔ واقعی، مقدار HTTPS را با `-PARAK_API_BASE_URL=https://shop.example.com/api` تنظیم کنید. کلید امضای خصوصی باید بیرون مخزن نگه داشته شود.
- قیمت‌ها در فرم مدیر به ریال ثبت می‌شوند. تغییر موجودی در پنل مدیر یا ثبت سفارش از همان پایگاه داده اعمال می‌شود.
