# اراک کالا برای اندروید

نسخهٔ ۱.۱.۰ با شناسهٔ بستهٔ `ir.arakkala.shop`، تم و آیکن مستقل ساخته شده است. روی اندروید ۷ به بالا نصب مستقل دارد. فایل تحویلی با کلید آزمایشی امضا شده است.

## اتصال فروشگاه

در `app/src/main/res/values/strings.xml`، مقدار `store_url` را روی نشانی HTTPS صفحهٔ شروع سامانهٔ اختصاصی اراک کالا بگذارید. تا وقتی این مقدار خالی است، برنامه فقط صفحهٔ وضعیت را نمایش می‌دهد و سامانهٔ فروشگاهی باز نمی‌کند.

پس از تنظیم نشانی، صفحهٔ اصلی و پیمایش داخل برنامه باید روی همان طرح، میزبان و درگاه بمانند. بارگذاری مستقیم منابع از نشانی‌های بیرونی مسدود است. قابلیت‌های وبی که به نشانی‌های بیرونی، درگاه پرداخت بیرونی یا منابع میزبان دیگر نیاز دارند باید هنگام اتصال بررسی شوند.

ثبت‌نام عمومی فروشگاه‌ها باید در وب و API غیرفعال باشد. سرور باید عملیات و داده‌ها را به شناسهٔ ثابت فروشگاه اراک کالا محدود کند و مجوز مدیر را در هر عملیات مرتبط بررسی کند. APK فعلی سامانهٔ وب، پایگاه داده، حساب مدیر و داده‌های قبلی را همراه ندارد. انتخاب فایل با انتخاب‌گر اندروید انجام می‌شود. این نسخه برای دوربین، میکروفون یا مکان مجوز درخواست نمی‌کند.

## ساخت APK

با Gradle 8.13 و ابزارهای ساخت 36 می‌توانید پروژه را در Android Studio باز کنید. برای ساخت مستقیم، JDK 17 یا بالاتر، Python 3، پلتفرم Android 36 و Android SDK Build Tools 36.0.0 لازم است. پس از تعیین `JAVA_HOME` و `ANDROID_HOME` اجرا کنید.

```text
python build_apk.py
```

خروجی `Arak-Kala-unsigned.apk` آمادهٔ امضا با `apksigner` است. کلید امضا را بیرون از پروژه نگه دارید.

## بررسی نسخهٔ تحویلی

ساخت مستقیم با ابزارهای رسمی اندروید، صحت امضا، چیدمان ZIP بسته، نام نمایشی، شناسهٔ بسته و نبود شناسه‌ها و دامنه‌های قبلی بررسی شدند. نشانی خالی، HTTP، میزبان متفاوت و درگاه متفاوت در آزمون بررسی نشانی پذیرفته نشدند. نصب روی گوشی، ورود مدیر، ثبت‌نام و سازگاری با سامانهٔ فعال هنوز آزموده نشده‌اند.
