# اراک کالا | نسخهٔ آزمایشی سامانهٔ تک‌فروشگاهی

این بسته بخش وبی است که اپ اندروید پس از تعیین دامنهٔ HTTPS باز می‌کند. یک فروشگاه پشتیبانی می‌شود و مسیری برای ایجاد فروشگاه جدید وجود ندارد. تنها حساب مجاز مدیریت `hossean787@gmail.com` است. حساب مشتری مستقل است و اجازهٔ مدیریت ندارد.

## امکانات پیاده‌شده

- ویترین فارسی واکنش‌گرا با جست‌وجو، دسته‌بندی، مرتب‌سازی، جزئیات و قیمت با تخفیف
- سبد خرید، ثبت سفارش، کد پیگیری و نمایش وضعیت با کد و موبایل
- ثبت‌نام و ورود مشتری با موبایل یا نام کاربری و فهرست سفارش‌های همان حساب
- مدیریت کالا، قیمت، تخفیف و ورود موجودی، همراه ثبت گردش انبار
- فهرست سفارش‌ها، تأیید، ارسال، تحویل و لغو با بازگرداندن موجودی
- فروش حضوری چندردیفی، رسید قابل چاپ و گزارش ریالی با فیلتر تاریخ میلادی

ثبت سفارش اینترنتی در این نسخه بدون دریافت وجه انجام می‌شود. درگاه، روش‌ها و هزینهٔ ارسال، تصویر محصول، احراز موبایل، بازیابی رمز خودکار، حسابداری کامل و انتقال دادهٔ موجود پیاده نشده‌اند. برای بررسی امکانات باقی‌ماندهٔ نسخهٔ مرجع باید منوهای پنل قابل مشاهده یا مستندات آن بررسی شوند. هیچ محصول، سفارش، رمز یا حساب واقعی در بسته قرار ندارد.

## اجرای محلی

با Python 3.10 یا بالاتر در پوشهٔ پروژه یک محیط مجازی بسازید و آن را فعال کنید. سپس اجرا کنید.

```sh
python -m pip install -r requirements.txt
export ARAK_DEVELOPMENT=1
python manage.py migrate
python manage.py setup_manager
python manage.py runserver
```

`setup_manager` رمز را در ترمینال مخفیانه از اپراتور می‌گیرد. اجرای دوبارهٔ آن رمز همان حساب را تغییر می‌دهد. برای مرورگر محلی از نشانی `http://127.0.0.1:8000/` و برای ورود مدیر از مسیر `/manager/login/` استفاده کنید. ورودی `ARAK_DEVELOPMENT` در PowerShell با `$env:ARAK_DEVELOPMENT = "1"` تعیین می‌شود.

## استقرار بعد از تهیهٔ میزبان

در محیط میزبان مقدار تصادفی و محرمانهٔ `ARAK_SECRET_KEY` و نام دامنه در `ARAK_ALLOWED_HOSTS` را تنظیم کنید و `ARAK_DEVELOPMENT` را بردارید. مسیر پایگاه داده را با `ARAK_DB_PATH` روی پوشهٔ پایدار، قابل پشتیبان‌گیری و دارای دسترسی محدود بگذارید. مهاجرت و تنظیم حساب مدیر را در همان محیط انجام دهید. فایل‌های استاتیک را با `python manage.py collectstatic --noinput` برای ارائه از مسیر `/static/` آماده کنید.

Gunicorn را روی یک اتصال داخلی راه‌اندازی کنید و پراکسی HTTPS را جلوی برنامه بگذارید. اگر پراکسی محلی در هر درخواست مقدار `X-Forwarded-Proto` را جایگزین می‌کند و دسترسی مستقیم عمومی به Gunicorn بسته است، `ARAK_TRUST_LOCAL_PROXY=1` را تنظیم کنید. روی مسیرهای ورود و ثبت‌نام محدودیت درخواست اعمال کنید. بعد از آزمودن HTTPS و دادهٔ نمونه، نشانی HTTPS را در مقدار `store_url` سورس اندروید قرار دهید و APK را دوباره بسازید.

## آزمون

پس از نصب وابستگی‌ها و فعال‌کردن تنظیمات محلی، `python manage.py test store` را اجرا کنید. پنج آزمون، محدودیت مدیر، جدایی حساب مشتریان، ثبت و پیگیری و لغو سفارش، کمبود موجودی، تکرار درخواست ثبت فروش، گردش انبار و CSRF را بررسی می‌کنند. نصب روی سرور عمومی و اتصال APK هنوز انجام نشده‌اند.
