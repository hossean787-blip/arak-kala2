# پرداخت آزمایشی، رسید و بررسی مرجوعی
زرین‌پال فقط به‌عنوان گزینه Sandbox اولیه انتخاب شده؛ مشخصات API از نمونه‌های عمومی REST v4 استخراج شده و هنوز با پذیرنده واقعی یا سرویس Sandbox بیرونی آزموده نشده است. هیچ مسیر پرداخت تولیدی یا پرچم پرداخت واقعی ایجاد نشده است. حالت پیش‌فرض غیرفعال است؛ فقط در محیط staging مستقل با ARAK_ISOLATED_STAGING=1، ARAK_SANDBOX_PAYMENTS=1، ARAK_SANDBOX_MERCHANT_ID و ARAK_PUBLIC_ORIGIN تأییدشده HTTPS فعال شود. داده واقعی مشتری در staging وارد نشود. درخواست و verify از مبلغ ذخیره‌شده، authority و مسیر ثابت Sandbox استفاده می‌کنند؛ callback به‌تنهایی موفقیت نیست. ایجاد مبهم خودکار تکرار نمی‌شود. آزمون واحد با mock، نه ارتباط واقعی. برای تولید، انتخاب نهایی پذیرنده، مستندات رسمی معتبر، verify و تطبیق مالی، idempotency provider، زمان‌بندی رزرو، برگشت وجه و تست واقعی لازم است.
رسید چاپی خلاصه سفارش است، نه فاکتور رسمی یا تأیید وصول. درخواست مرجوعی فقط برای مشتری مالک سفارش تحویل‌شده ثبت می‌شود؛ بررسی مدیر هیچ موجودی، پرداخت یا استرداد وجهی را تغییر نمی‌دهد. سیاست مرجوعی، شرایط حقوقی و تسویه باید پیش از انتشار تعیین شوند.
