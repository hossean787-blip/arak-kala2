# Checkout foundation
Fixed-amount manager-controlled coupons with minimum cart and usage cap, configurable shipping methods (none enabled by default), actual price/discount/shipping snapshots, signed 15-minute quote for the web flow and transactional stock/coupon validation. Cancelled orders release coupon capacity. Existing orders backfilled without changing totals. API accepts optional shipping and coupon fields; response retains total and adds breakdown. Order summary is explicitly unpaid, not a fiscal invoice. No provider integration, payment capture, tax calculation, shipping carrier or actual customer data. Those require verified merchant/domain configuration, commercial terms and live end-to-end acceptance.
