# Multi-page public storefront
Public pages are now server-rendered Django routes, with a shared RTL visual shell. Existing /shop/ and /manager/ paths and shared Android API remain functional. One session cart is used; old browser cart is migrated by CSRF-protected endpoint on first load, capped to active inventory and 30 rows. Favorites are session-based (not cross-device). Saved addresses have owner-scoped CRUD and checkout selection. Guest checkout remains supported; payment and shipping remain disabled. Contact and policy pages clearly mark missing commercial details. Browser tests cover five viewport widths and direct URL navigation, plus existing integration tests. No production deployment or payment access.
