# Phase 4 — web owner management
Dedicated management navigation and responsive product cards; category/status and order filters; low-stock alerts; owner-only image uploads using the same normalizer as Android; max eight images, cover selection, unlink without deleting physical files, version conflict detection. Stock adjustment checks expected stock and posts a movement in the same transaction. Date-bounded aggregate reporting and CSV distinguish unpaid online order values from recorded POS sales. No payment processing, discount-code checkout, production deployment, or changes to Android API contract. Physical orphan cleanup is deferred to a separately approved retention policy.
