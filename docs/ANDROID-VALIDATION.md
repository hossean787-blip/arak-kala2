# Android readiness improvements
Pure Kotlin validation of Persian/Arabic digits, server price and stock limits, discount and text lengths, image sampling. Added four JVM tests. Product editor supports SKU, barcode, discount and image reference removal/cover selection; sends image changes only when needed, with expected image list for stale-write protection. Older API clients without expected_images remain compatible and do not gain the new conflict protection. Decode bounds before image allocation; no full-resolution unbounded decode. No physical device run or release signing performed.
