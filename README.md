# اراک کالا ۲ — بازیابی و انتقال منابع قدیمی

این بسته، **آرشیو بازیابی‌شده از پروژه پیشین اراک کالا** است؛ نه نسخه تجاری آماده و نه کپی از داده‌های زنده سرور.

## ساختار
- `backend/` — سورس واقعی فروشگاه تک‌فروشگاهی Django (نمایش کالا، حساب مشتری، سبد، سفارش، رهگیری و پنل مدیر/انبار/فروش حضوری)
- `android/` — سورس واقعی اندروید نسخه 1.1.0؛ یک پوسته WebView برای وب‌سایت، نه اپ اختصاصی تکمیل‌شده مدیریت محصولات
- `design-references/` — طرح‌ها و نمونه‌های قبلی؛ **تصویب نهایی طرح نیستند**. نمونه HTML مستقل فاقد CSS/JS همراه است.
- `legacy-archives/` — ZIPها و APKهای آرشیوی برای مقایسه و بازگشت؛ کد استخراج‌شده از برنامه مرجع دتا صرفاً مرجع بررسی است و با سورس اراک کالا ترکیب نشده.
- `docs/STATUS.md` — نیازمندی‌های تثبیت‌شده و شواهد آزمون/محدودیت‌ها
- `docs/FILES-SHA256.json` — فهرست SHA-256 فایل‌های قابل بازیابی

## محدودیت داده‌ها
هیچ پایگاه داده واقعی یا اطلاعات مشتری/سفارش/محصول از سرور قبلی بازیابی نشده است. هیچ محصول فرضی برای فروشگاه جدید تعریف نشده. کد backend حاوی مهاجرت‌های ساختار DB است، نه رکوردهای واقعی.

## اجرای محلی backend
Python 3.10+ لازم است. از پوشه `backend`:
```bash
python -m pip install -r requirements.txt
export ARAK_DEVELOPMENT=1
python manage.py migrate
python manage.py setup_manager
python manage.py runserver
```
برای محیط عمومی باید HTTPS، دامنه، کلید امن، نگه‌داری داده، پرداخت و امنیت مستقر و آزموده شوند؛ برای این بسته تأیید نشده‌اند.

## حدود انتقال
منابع فقط از نام پروژه «اراک کالا» و فایل‌های مرتبط بازیابی شده‌اند. فایل‌های پروژه‌های مستقل دیگری وارد نشده‌اند. آرشیو دتا صرفاً یک مرجع تاریخی جداگانه است و نباید بدون بررسی مجوز و امنیت منتشر شود.
